# Support

For usage questions, first check the [user guide](docs/USER_GUIDE.md), [README](README.md), and existing [issues](https://github.com/ThomasCrouzet/mdsh/issues).

Use the bug report template for reproducible defects and include the app version, browser or operating system, steps, expected behavior, and relevant console output with secrets removed. Use the feature template for a scoped proposal that preserves offline operation and the local-first model.

Support is community-based and best effort. The project does not provide private consulting, guaranteed response times, account recovery, cloud data recovery, or recovery of an encrypted backup whose passphrase was lost.

Do not report vulnerabilities or conduct incidents in a public issue. Follow [SECURITY.md](SECURITY.md) or [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
