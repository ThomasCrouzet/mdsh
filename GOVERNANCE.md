# Governance

mdsh editor is solo-maintained by [Thomas Crouzet](https://github.com/ThomasCrouzet). Contributions are welcome within the deliberately narrow local-first scope.

The maintainer makes final decisions on releases, architecture, security response, roadmap, moderation, and project scope. Decisions favor offline operation, user control of data, a small initial bundle, accessibility, and maintainable behavior over feature breadth. Material changes should start with an issue so tradeoffs are recorded before implementation.

Reviews and responses are best effort. No response-time guarantee is implied. Security and conduct reports use the private channel documented in [SECURITY.md](SECURITY.md).

If regular maintenance stops, the maintainer will try to publish a status note and either identify a trusted successor with repository access or archive the project in a read-only state. No contributor is entitled to credentials, releases, or transfer of the project name.
